# 🚀 AfriTalent

> Plateforme de mise en relation entre freelances tech et entreprises en Afrique.

---

## 📋 Description

AfriTalent est une plateforme fictive qui connecte les talents tech africains avec des entreprises à la recherche de compétences. Le site présente les fonctionnalités de la plateforme, les tarifs, des profils de freelances et permet de convaincre les visiteurs de s'inscrire.

**Projet réalisé dans le cadre du Semestre 2 - Développement Web**

## ✨ Fonctionnalités principales

1. **Dark Mode / Light Mode** 🌙 - Toggle dans la navbar, sauvegardé dans localStorage
2. **Compteurs animés** 🔢 - S'incrémentent au scroll avec IntersectionObserver
3. **Filtrage dynamique** 🔍 - Filtrage des freelances par catégorie sans rechargement
4. **Validation de formulaire** ✅ - Tous les champs requis, regex email, message 20 caractères
5. **Navbar dynamique** 📌 - Change de style au scroll (effet shrink)
6. **Bouton retour en haut** ⬆️ - Apparaît au scroll, smooth scroll
7. **Animation au scroll** ✨ - Fade-in des sections avec IntersectionObserver

## 🚀 Installation et lancement local


3. **Lancer le site**
